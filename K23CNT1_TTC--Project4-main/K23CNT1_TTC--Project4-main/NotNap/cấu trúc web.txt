===========================
DỰ ÁN WEBSITE G9 TRANG SỨC
===========================

Công nghệ sử dụng (đúng theo thư mục `G9_Trangsuc`):
- Backend: Python Flask + Flask-Cors
- Database: Microsoft SQL Server (pyodbc)
- Auth: JWT (PyJWT) + Google OAuth (Authlib)
- Payment: PayPal REST (requests)
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Dashboard: Chart.js
- Quản lý cấu hình: python-dotenv (.env)
- Quản lý source: Git / GitHub

=========================================================
API MODULES (đúng theo `backend/app.py` + `routes/__init__.py`)
=========================================================

Các blueprint và url_prefix:
- /api/auth        -> `routes/auth/auth_routes.py` (đăng nhập/đăng ký/JWT/Google OAuth callback)
- /api/products    -> `routes/products/product_routes.py` (danh sách/chi tiết/tìm kiếm sản phẩm)
- /api/categories  -> `routes/products/category_routes.py` (danh mục)
- /api/reviews     -> `routes/products/review_routes.py` (đánh giá sản phẩm)
- /api/cart        -> `routes/cart_checkout/cart_routes.py` (giỏ hàng)
- /api/orders      -> `routes/cart_checkout/order_routes.py` (đơn hàng)
- /api/user        -> `routes/account/user_routes.py` (tài khoản người dùng)
- /api/admin       -> `routes/admin_management/admin_routes.py` (quản trị)
- /api/dashboard   -> `routes/admin_management/dashboard_routes.py` (thống kê)
- /api/news        -> `routes/news/news_routes.py` (tin tức)
- /api/gold        -> `routes/gold/gold_routes.py` (giá vàng)
- /api/promotions  -> `routes/promotions/promotion_routes.py` (khuyến mãi)
- /api/upload      -> `routes/uploads/upload_routes.py` (upload ảnh/file)
- /api/paypal      -> `routes/payments/paypal_routes.py` (tạo/confirm thanh toán PayPal)

Ngoài API, `backend/app.py` còn serve frontend:
- `/` -> `frontend/user/index.html`
- `/uploads/<file>` và `/news/<file>` -> serve file từ `backend/uploads/`


=========================================================
CHỨC NĂNG WEBSITE 
=========================================================

KHÁCH HÀNG:
- Đăng ký / Đăng nhập (JWT)
- Đăng nhập Google (OAuth) qua `google-callback.html`
- Quản lý hồ sơ: xem/cập nhật thông tin cơ bản
- Xem danh sách sản phẩm, lọc/tìm kiếm, xem chi tiết
- Giỏ hàng: thêm/sửa/xóa sản phẩm
- Đặt hàng: checkout, tạo đơn hàng
- Thanh toán PayPal: thành công/thất bại 
- Theo dõi danh sách đơn hàng + xem chi tiết đơn
- Đánh giá sản phẩm
- Xem giá vàng
- Xem tin tức + chi tiết tin tức

ADMIN:
- Dashboard thống kê
- CRUD sản phẩm
- CRUD danh mục
- CRUD đơn hàng + xem chi tiết
- Quản lý người dùng
- CRUD tin tức
- CRUD giá vàng
- Quản lý khuyến mãi
